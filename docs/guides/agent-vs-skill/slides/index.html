AGENTvsSKILL

에이전트 vs 스킬 — 채용한 일꾼인가, 펴 보는 매뉴얼인가

Claude · GitHub Copilot · OpenAI Codex
01SUMMARY · 한 줄 요약

한 줄이면 일꾼이거나 매뉴얼

Agent · 에이전트

전문 일꾼

자체 컨텍스트·도구·권한·판단으로 위임받은 일감을 통째로 끝까지 수행하고 요약만 반환.

Skill · 스킬

작업 매뉴얼

특정 작업 수행법을 묶은 SKILL.md 플레이북. description이 맞을 때만 펼쳐져 컨텍스트를 아낌.

02ANALOGY · 사무실 풍경

채용할까, 펼칠까

에이전트

🧑‍💼 채용한 전문가

자기 책상(별도 컨텍스트)·도구·판단으로 일을 통째로 맡아 끝낸다.

스킬

📚 책장 속 매뉴얼

관련 작업을 만났을 때만 꺼내 펼친다. 평소엔 자리를 거의 안 차지.

03DEFINITION · 한 줄 정의

정확히 말하면

Agent

자체 컨텍스트·도구·권한·판단을 갖고 위임받은 작업을 수행하는 재사용 가능한 전문 일꾼(페르소나) 정의.

Skill

작업 수행법을 instructions·스크립트·리소스로 묶은 SKILL.md 폴더로, description 매칭 시 본문이 로드되는 재사용 플레이북.

07DECISION · 언제 무엇을

일꾼을 부를까, 매뉴얼을 펼칠까

에이전트를 쓸 때
  • 한 역할(리뷰어·테스트·보안)을 분리된 맥락에서 통째로
  • 작업이 길거나 메인 컨텍스트 오염 방지
  • 권한·도구 격리 · 멀티에이전트 오케스트레이션
스킬을 쓸 때
  • 작업 절차·도메인 지식을 여러 곳에서 재사용
  • 평소 컨텍스트를 안 차지하게 (점진적 공개)
  • 스크립트·템플릿·참조문서를 번들로 배포
//SUMMARY
AGENT는 일꾼,
SKILL은 매뉴얼.
