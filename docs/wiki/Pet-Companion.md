# Pet Companion

Pet Companion is the repository package for publishing cross-runtime pet and companion workflows without exposing private local assets.

## What It Includes

- shared schemas for bundle and state contracts
- a public-safe `Nori` sample
- a lightweight browser viewer
- adapter guidance for Codex, Claude Code, GitHub Copilot, OpenClaw, and Paperclip

## Current Status

| Runtime | Status In Repo |
| --- | --- |
| Codex | Usable |
| Claude Code | Not implemented as a working integration |
| GitHub Copilot | Not implemented as a working integration |
| OpenClaw | Partial provider example |
| Paperclip | Partial provider example |

## Important Limit

This package is a starter workflow and documentation bundle, not a one-click installer.

For the current public-facing details, start from:

- `packages/pet-companion/README.md`
- `packages/pet-companion/docs/compat-matrix.md`
- `packages/pet-companion/examples/nori-public-case/`
