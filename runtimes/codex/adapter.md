# Codex Adapter

Codex is best used as the execution, verification, repair, and integration owner.

## Native Surfaces

- `AGENTS.md`
- Codex skills
- local filesystem inspection
- terminal commands
- tests, builds, and browser checks

## Mapping

| Core concept | Codex translation |
| --- | --- |
| Package | skill folder plus operating notes |
| Worker | main thread or available sub-agent tooling |
| Evidence | file paths, command output, logs, screenshots |
| Completion | final response with verified evidence |

## Rule

Do not close a task from a chat response alone. Close only after evidence exists.
