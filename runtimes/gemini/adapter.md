# Gemini Adapter

Gemini packages should be expressed as system prompts, context files, and workflow instructions.

## Native Surfaces

- `GEMINI.md`
- system prompts
- task-specific context
- Google workspace integrations where available

## Mapping

| Core concept | Gemini translation |
| --- | --- |
| Package | prompt pack |
| Runtime adapter | `GEMINI.md` instructions |
| Evidence | cited files, links, generated artifacts, verification notes |

## Rule

Gemini output should be normalized back into the shared evidence-first lifecycle before closure.
