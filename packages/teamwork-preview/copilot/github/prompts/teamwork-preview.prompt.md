# Teamwork Preview

Create a launch packet for delegated or parallel work.

Do not implement yet unless the user explicitly asks for execution after reviewing the packet.

## Process

1. Lock the goal in one sentence.
2. Run a grill-me pass:
   - missing source evidence
   - ambiguous scope
   - subjective acceptance criteria
   - unverified paths or runtime capability
   - stop conditions
3. Produce a launch packet:
   - objective
   - context
   - paths
   - in scope
   - out of scope
   - branch plan
   - acceptance criteria
   - verification steps
   - return format
4. Ask for approval before delegated execution.
5. If execution proceeds, keep the main chat as final acceptance owner.

## Output

```markdown
## Goal

## Grill-Me Findings

## Launch Packet

## Approval Needed

## Verification Plan
```
