# Teamwork Preview

Use this command-style reference to prepare delegated work before launching agents.

## Intent

Build a worker-ready prompt with objective scope, source evidence, branch plan, acceptance criteria, verification needs, stop conditions, and return format.

Do not treat this as execution. Treat it as the launch gate before execution.

## Steps

1. Lock the goal.
2. Run a grill-me pass against the request.
3. Draft the launch packet.
4. Ask for approval.
5. On approval, delegate only independent branches.
6. Collect evidence and unresolved risks.
7. Keep the main session as final acceptance owner.

## Launch Packet Shape

```markdown
# Teamwork Launch Packet

## Objective

## Context

## Paths

## Scope

## Source Evidence To Inspect

## Stop Conditions

## Return Format
```
