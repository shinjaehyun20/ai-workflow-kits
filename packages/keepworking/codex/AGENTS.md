# Keepworking For Codex

Use the `keepworking` skill for non-trivial tasks that require persistence, verification, repair, or repeated checks.

## Operating Rule

Do not close from explanation alone. Close with evidence:

- changed files
- test or build output
- logs
- screenshots
- structured manifests
- unresolved risks

## Tier Defaults

| Tier | Codex behavior |
| --- | --- |
| `simple` | inspect, search, classify, summarize |
| `medium` | make scoped edits and verify |
| `complex` | stage the work, validate assumptions, report risks |

## Final Report

Include:

- goal
- tier
- files changed or inspected
- checks run
- evidence
- unresolved risks
