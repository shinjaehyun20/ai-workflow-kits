# keepworking

## Goal

Keep complex work moving until evidence exists.

## Core Loop

1. Restate the current goal in one line.
2. Split unknowns into discoverable facts and preferences.
3. Rank next work by leverage and risk.
4. Pick the smallest useful next slice.
5. Execute or inspect.
6. Verify with evidence.
7. If verification fails, repair and re-verify.
8. Close with evidence paths and unresolved risks.

## Output

- Current Goal
- Priority
- Next Deep-Dive Target
- Verification / Missing Evidence
- Continue / Close Decision
