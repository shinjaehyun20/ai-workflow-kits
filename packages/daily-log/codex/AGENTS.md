# Daily Log For Codex

Use the `daily-log` skill to append today's Codex activity to the shared daily log.

## Operating Rule

Do not close from explanation alone. Close with evidence:

- the log file path where the entry was written
- confirmation that the `[Codex]` section changed
- confirmation that no other section changed

## Section Rule

Codex writes only to `## [Codex]`. All other sections are read-only.

Never rewrite the full file. Append only.

## Tier

Daily log is always `simple` tier. One focused append with verification.

## Final Report

Include:

- date
- log file path
- section appended
- number of bullets written
- verification result
- other sections: unchanged (confirm)
