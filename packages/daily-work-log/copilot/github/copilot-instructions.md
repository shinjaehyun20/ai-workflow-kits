# Daily Work Log — Copilot Instructions

Use `../../WORK_LOG_CONTRACT.md` as the shared contract when handling daily work-log requests.

- Keep the record date-bounded and evidence-backed.
- Preserve existing work-log content; use an append or minimal item correction.
- Include source coverage, status, evidence, confirmed owner scope, blockers, and next actions.
- Do not infer personal work or completion from generated artifacts or timestamps.
- A saved local draft is not an external send, publication, or approval.
- State that the daily record is priority source input to `weekly-report-evidence`.
