# Daily Work Log

Follow `../../WORK_LOG_CONTRACT.md` as the source contract.

1. Lock date, source coverage, target file, and verifier.
2. Preserve existing work-log entries; append or minimally correct an item.
3. Record status, evidence, confirmed owner scope, blocker, and next action for every work item.
4. Keep unavailable evidence as a coverage gap, not a no-work finding.
5. Save locally, read back, and distinguish local save from external send, publication, or approval.
6. Tell the user that this log is priority input for `weekly-report-evidence`.
