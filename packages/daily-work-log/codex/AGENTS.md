# Daily Work Log for Codex

Use the `daily-work-log` skill for daily work records. The source of truth is `../../WORK_LOG_CONTRACT.md`.

## Boundary

- Record verified work facts, not a personal diary or an AI-session transcript.
- Preserve existing log content; append or minimally edit the relevant item.
- Do not send, publish, or approve anything unless separately requested.

## Close Evidence

Report the work date, source coverage, save path, changed item count, read-back result, and unresolved coverage gaps.
