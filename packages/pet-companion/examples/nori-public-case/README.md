# Nori Public Case

`Nori` is the sample character for this package.

This example demonstrates:

- a public-safe companion bundle
- shared runtime state mapping
- runtime notes without private installation details

It intentionally does not include:

- production sprite binaries
- local install paths
- private logs
- devlog content

Open `runtime-adapters.json` for the bundle contract and `flow.md` for the public publishing flow.
