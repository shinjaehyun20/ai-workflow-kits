# Pet Companion For Codex

Use the `pet-companion` skill when the task is to publish, document, validate, or adapt a pet workflow for Codex and adjacent runtimes.

## Rules

- Separate native Codex pet packaging from cross-runtime viewer packaging.
- Prefer public-safe SVG and JSON examples over private local artifacts.
- Keep the shared state contract small and stable.
- Close with evidence such as file paths, schema validation, viewer checks, or unresolved limits.
