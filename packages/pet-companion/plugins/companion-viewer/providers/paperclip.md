# Paperclip Provider Notes

Treat Paperclip as a widget or overlay example only.

## Recommended Flow

1. Keep Paperclip control-plane artifacts untouched.
2. Render the companion in a dashboard or browser overlay.
3. Write runtime state into the shared `companion-state.json` contract.

## Mode

`widget_overlay`

## Notes

- Do not assume a native pet slot.
- Do not blend status rendering with the core service artifact contract.
