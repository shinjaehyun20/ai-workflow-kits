# Evidence-Backed Weekly Report

Read `../../../../REPORT_CONTRACT.md` before drafting.

## Workflow

1. Lock reporting period, timezone, audience, output target, and verifier.
2. Read the covered `daily-work-log` records first; add each source to a coverage ledger.
3. Treat a missing log or unavailable source as a coverage gap, not no work.
4. Reconcile every prior-plan item as completed, in progress, not started, or confirmation needed.
5. Use supplementary meeting, decision, approval, message, or change evidence only to resolve supported facts.
6. Separate artifact existence from confirmed human contribution.
7. Write key work, next plan, verified outcomes, issues, decisions needed, and notes/open questions.
8. Save locally and read back. Do not send, publish, or approve without a separate explicit request.

## Do Not

- skip prior-plan items;
- promote `in progress` to completed;
- claim generated-only output as personal performance;
- infer no work from missing coverage;
- treat a local draft as external delivery.
