# Evidence-Backed Weekly Report Contract

## Inputs

1. Reporting period and timezone.
2. Date-bounded records from `daily-work-log` or an equivalent organization-owned work log.
3. Prior report or prior-week plan when available.
4. Supplementary meeting, decision, approval, message, schedule, or change evidence.
5. Audience, output target, and external-send boundary.

## Source Order

1. Daily work logs in the reporting period.
2. Prior report and its next-week plan.
3. Meeting and decision records.
4. Approved communication and change history.
5. Schedule or mail records when needed to resolve a material gap.

Record each source as `collected`, `empty`, `unavailable`, `failed`, or `not_applicable`. Do not translate a missing daily log into no work.

## Required Output

1. This week's key work
2. Next week's plan
3. Verified outcomes or changes
4. Issues and dependencies
5. Proposals or decisions needed
6. Notes, open questions, and coverage gaps

## Prior-plan Reconciliation

Every prior-plan item is classified as `completed`, `in progress`, `not started`, or `confirmation needed`. New work appears only when current-period evidence exists.

## Attribution Rules

An artifact existing does not prove a person's work. Attribute only a confirmed action such as review, decision, edit, approval, or communication. Do not claim an automated draft or another person's work as individual performance.

## Close Gate

Save locally, read the report back, and verify required sections, source coverage, reconciliation completeness, and unknown-state handling. Sending, publishing, and approval require a separate explicit action.
