# Evidence-Backed Weekly Report

Follow `../../REPORT_CONTRACT.md`.

1. Read the requested date-range `daily-work-log` records before drafting.
2. Record source coverage and use missing records as coverage gaps, not no-work proof.
3. Reconcile every prior-plan task as completed, in progress, not started, or confirmation needed.
4. Attribute only confirmed review, decision, edit, approval, or communication.
5. Include key work, next-week plan, verified outcomes, issues, decisions needed, and open questions.
6. Save locally and read back. Keep external send, publication, and approval outside this workflow unless explicitly requested.
