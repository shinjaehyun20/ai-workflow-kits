# Example — Weekly Report from Daily Work Logs

## Request

Create a weekly report from the work logs for the reporting period and the prior plan. One prior item has evidence of progress but no final confirmation. A generated draft has no evidence of human review. Save locally only.

## Required behavior

1. Review all date-bounded `daily-work-log` records first.
2. Record unavailable dates or sources as coverage gaps.
3. Reconcile every prior-plan item.
4. Keep the partially evidenced item `in progress`.
5. Keep the generated-only draft out of individual-performance claims.
6. Write required report sections and list open questions.
7. Confirm the draft is local only; do not claim send, publication, or approval.

## Expected handoff

The report cites the date range and source labels from daily work records, not private paths or customer identifiers.
