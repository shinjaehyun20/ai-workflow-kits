# Evidence-Backed Weekly Report — Copilot Instructions

Use `../../REPORT_CONTRACT.md` for weekly-report requests.

- Read date-bounded `daily-work-log` records first.
- Maintain source coverage and do not treat gaps as no work.
- Reconcile all prior-plan items.
- Attribute only supported human actions.
- Save and read back a local report before calling it complete.
- Do not equate a saved draft with external send, publication, or approval.
